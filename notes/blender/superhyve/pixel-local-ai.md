# Pixel (Local AI)

親: [[superhive-blender-gamedev-tools]]

https://superhivemarket.com/products/pixelai

## TL;DR

- 画像・テキスト → **シームレステクスチャ + PBR マップ** (albedo / roughness / normal / height / metallic / AO)。シーム修正、ライティング除去、アップスケール。
- **レイヤーエディタ** (マスク・ブレンドモード・不透明度) を Blender 内に持つ。
- ページの「Requirement」欄が空で、バックエンド (ローカルかクラウドか、モデル) が不明。タイトルは "Local AI" だが裏付けなし。
- $10、評価なし、販売 10+。素材生成は [[texturaizer]] / ComfyUI 直接の方が実績・透明性が高い。優先度低。

## 価格・状態

- 作者 BlendR6。$10。販売 10+、評価なし。公開 5 か月前。Blender 4.0〜5.1。GPL。

## 機能 (ページ記載)

- Text to Material (木・大理石・布など)。
- Generate PBR Maps。
- シーム除去、ライティング除去、アップスケール。
- AI Rendering (元画像と生成段階の比較)。
- Layer Editor。更新は継続中と記載。

## 注意

- 要件・モデル・商用条件の記載なし。購入前に作者へ質問するか、見送り。
- ゲーム用 PBR は、ComfyUI + 既存の PBR 生成ワークフロー (Windows PC) で代替できる。
