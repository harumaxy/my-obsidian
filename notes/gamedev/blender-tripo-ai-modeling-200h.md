## 概要

Tripo提供、AI×3Dモデリング200時間検証動画。シフトA(Blenderメッシュ手動生成)一切なしでキャラ完成レベル到達。

## 発見11工程ワークフロー

1. 画像生成(マルチビュー推奨、複雑キャラほどパーツ分解要)
2. Tripoで3Dモデル生成 → メッシュ綺麗さ優先選択、テクスチャーは後回し
3. Blenderでスカルプト修正
4. TripoのSmart Meshでローポリ化
5. Blenderでリトポロジー → 目口周りが最難関、RetopoFlow使用
6. UV展開 → AI苦手分野、手動最適化必須
7. テクスチャーベイク or Modddifで再生成
8. Blenderでテクスチャーペイント修正(スミアで馴染ませ)
9. リギング → AccuRig or Blender Auto-Rig Pro
10. Unityインポート

## 時間配分ログ

- 0-20h: AIモデリング動画リサーチ、情報収集
- 20-100h: キャラ1体目制作。初挑戦のため8h/体ペース。ワークフロー確立
- 100-148h: 敵キャラ・武器量産フェーズ
  - 量産自体は1体30分ペース到達
  - ただし自動化検証(Claude Code + Tripo API/Web版操作)に25h浪費 → 結論: トークン/クレジット大量消費でコスパ悪い、非現実的
  - Web版Tripo手動操作 + 要所だけ人間修正が結局最速ルート
- 148-200h: 背景素材・フィールド作成、Unity実装(温泉フィールド等)

## 重要Tips

- **テクスチャー用画像とモデル生成用画像は別に作る**。形状完全一致画像でテクスチャー生成すると精度激増(武器・キャラ共通)
- 3D生成用画像は彩度高め推奨。暗い色は3D化時に飛ばされる仕様、狙った色に近づかない
- **UV展開してからTripoテクスチャー生成**すると重要部分の解像度確保できる。展開なしだと解像度がランダムに劣化(小さい面に重要ディテールが割り当てられがち)
- Smart Meshはポリゴン数指定がシビア。多すぎ/少なすぎで破綻。画像をChatGPT等に見せてポリゴン数の目安を聞くのもアリ
- Tripo: 色の一貫性強い、リアル調向き。Modddif: 手書き風向きだが生成重ねるほど一貫性崩れやすい(表裏で色違う等)
- キャラは頭と体を別画像で作る(後からサイズ調整不可のため)
- 衣装は先にキャラ完成させてから、そのキャラに合わせた衣装画像を生成した方がフィット良い
- デフォルメキャラよりリアル寄り・データ量多いモデルの方が生成成功率高い(データ量少ないと精度落ちる)
- テクスチャー解像度: 2K/4K/8Kで質감差大。拡大使用ならor リアル調なら8K検討
- 表面が平らな形状(SF武器等)はテクスチャーが綺麗に入りやすい

## 人間の手が必要な箇所(自動化できなかった部分)

- **顔トポロジー修正**: 目口周りのループ構造、RetopoFlowで手動リトポ。最難関、時間食う
- **UV展開**: AI苦手分野。手動最適化必須
- **テクスチャー細部修正**: 眉毛塗り直し、汚い部分の塗りつぶし、スミアでの馴染ませ

逆に完全自動化(Claude Code + Tripo API)は失敗判定。25h検証してコスパ悪すぎと結論。AIがやる部分は造形(一番難しい立体作成)とテクスチャー塗りと服デザイン、人間がやる部分はトポロジー整備・UV展開・仕上げ調整という役割分担に落ち着いた。単純作業だが工程数は多い構図。

## リギング・アニメーション

- リギングツール: AccuRig or Blender Auto-Rig Pro が主流。動画内の自動化検証(敵キャラ)ではAuto-Rig Pro使用、Claude Code経由でキャラ適用→マーカー設置まで自動化成功。その先は自動化失敗
- 表情アニメーション: リギングツールというよりトポロジー(顔のリトポ)側の話。目口周りにループ構造があれば瞬き・口開閉が動かせる。ブレンドシェイプ作成手順の詳細は本動画で未解説
- Unity側のモーション(武器エフェクト色変化等)の具体的作成方法は本動画で未解説。「別動画でキャラ作成ワークフロー解説予定」と予告あり

## Claude Code自動化の限界

- Tripo API + Claude Codeで完全自動化試行 → シンプル形状(岩人形)のみリギング一歩手前まで到達、複雑形状は失敗
- Web版Tripo操作をClaude Codeに代行させる方式も試行 → Smart Mesh使用で人型は高精度生成できたが、画像入れ違い等のミス多発、トークン消費激しく非現実的
- Claude(Fable 5、Maxプラン)でフィールド自動生成も試行 → 参考フィールドを見せるだけで敵配置・アイテムボックス・ゲート等含め理解して類似フィールド生成可能。ただしトークン消費激しく1日で上限到達、コスパ課題
