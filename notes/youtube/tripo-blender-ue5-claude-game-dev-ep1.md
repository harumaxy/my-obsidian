# Tripo + Claude + UE5 でゲーム制作 第1回

- URL: https://www.youtube.com/watch?v=5Zi7mWT_a7A
- 使うもの: Tripo, Blender, Unreal Engine 5, Claude Opus 5.5
- 投稿者 モデリング知識ゼロ。3Dモデル = Tripo。Blender 調整 + UE5 組込 = Claude 丸投げ
- 敵 + 自キャラ作る。UE5 で戦える所まで行く。3時間で基本動作。モデル差替え + 面白さ探し込みで 1日

## Tripo P2.0 新機能

- スマートメッシュ: 三角ポリゴンやめた。ネイティブ四角形 (クワッド) トポロジー出る
- 一括生成: 1リクエストで 4バリエーション同時。密度、形状表現違う。クレジット 1回分。使わないと損
- エッジループきれい。関節曲げ伸ばし強い。外部ツール持ってっても崩れにくい
- リギング: UE5 用ボーン選べる
- 部分編集: 黄色い選択ボックスで囲む。そこだけ再生成。全部やり直しより楽
- スマートUV: 詳細な展開図焼く。分割、結合、テクスチャ描き直しで崩れ防ぐ。Blender 経由なら必須
- テクスチャ 8K

## キャラ作り

- 雑魚敵: 和風妖怪。4バリエーションから選んでテクスチャ + リグ
- ボス: 橋姫。参照画像 → スマートメッシュ → 目の周り部分編集 → スマートUV → 8K テクスチャ
- プレイヤー: 顔、髪、胴体 別々に生成
  - 顔: HD モデル最高品質
  - ポリ数: 三角形で最大 200万まで設定可。今回 3万に抑えた (パフォーマンス考慮)
  - 胴体: アニメするから低ポリ

## Claude でゲーム化

- 事前に Claude と「Tripo → Blender → UE5」打合せ済み
- Tripo ブリッジでパーツ全部 Blender に直送。サイズ、形バラバラでもそのまま
- 完成予想図の参照画像つけて「作業しといて」→ Claude が組立
- ボーン + スカート等の物理 + 歩き、走りアニメまで Claude。ここまで約 1時間
- UE5 連携: 「UE5 インストールした、接続して」と伝えるだけ。勝手に連携して作業開始
- 歩き方「ガニ股気味」と言うと「モデル風」に作り直した
- 戦闘アニメは Mixamo から拝借。敵配置、ステージ設定も Claude
- 最後ボス討伐プレイ映像

## モーション

- 歩き、走り: Claude 作成 (手法 動画で説明なし)
- 戦闘: Mixamo
- リターゲット方法、Claude のモーション生成手法 不明 (字幕だけでは分からん)
