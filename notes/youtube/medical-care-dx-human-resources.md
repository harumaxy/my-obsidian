## 雑談メモ

### デジタル化とDXの違い

- デジタル化: 紙 → 電子カルテ。予約・受付・会計電子化。紙処方箋 → 電子処方箋。
- DX: 病院・診療所・薬局・介護施設またいで情報共有。重複検査・重複投薬防ぐ。オンライン診療。AI (画像診断支援、音声 → カルテ要約)。タスクシフト。

### ベンダー独自仕様問題

- 電子カルテメーカーごとに DB 構造、項目名、コード体系、出力形式バラバラ。
- 困りごと: 他社連携は個別開発で高い。乗り換え困難 (ベンダーロックイン)。病院間共有できない。
- 対策:
  - HL7 FHIR: 国際標準。REST + JSON。
  - 3文書6情報: 国が決めた標準共有項目。
  - 標準型電子カルテ: 国が標準実装用意。

### FHIR

- 仕様公開。無料。CC0。https://hl7.org/fhir/ (実運用 R4 多い。最新 R5)
- 日本版プロファイル = JP-CORE (日本HL7協会)。
- 試せる公開サーバー: https://hapi.fhir.org/baseR4 。OSS 実装は HAPI FHIR (Java)。
- 実際に叩いた:

```sh
# URL はクォート必須 (zsh で ? が glob 展開されて失敗する)
curl -H "Accept: application/fhir+json" "https://hapi.fhir.org/baseR4/Patient?_count=1"
curl -H "Accept: application/fhir+json" "https://hapi.fhir.org/baseR4/Observation?subject=Patient/nhanes-112200&_count=3"
```

- 構造:
  - Bundle (searchset) = 検索結果の箱。entry[] に中身。link.next でページング。
  - Patient: id, identifier (system + value), name[], gender, birthDate。
  - Observation: subject.reference で Patient を参照。リソース同士は参照でつながる。
    - code = LOINC (例 1920-8 = AST, 1742-6 = ALT, 1751-7 = アルブミン)。
    - valueQuantity = value + unit。単位は UCUM。
    - status: final / preliminary / amended。
    - category: laboratory, vital-signs など。
- 日本の検査コードは JLAC10 が主流。FHIR では LOINC との対応づけ・併記で標準化進む。
- 公開サーバーのデータは合成 (NHANES 実測 + 氏名・MRN・生年月日は生成)。実患者ではない。

### コーディングエージェントとの相性

- 向く: 仕様厳密 + 公式バリデータで機械的に検証できる。変換系定型作業。テストサーバーで動作確認。
- 難しい (人間必要):
  - 独自コード → LOINC/JLAC10 マッピング。医療知識必要。間違い = 臨床的に危険。
  - 現場データ汚れ (自由記載、欠損、運用ばらつき)。
  - 日本固有制約 (JP-CORE、3文書6情報)。
  - セキュリティ・規制 (3省2ガイドライン、同意、監査ログ)。実患者データをAIに渡せるか問題。
  - 既存電子カルテの内部 DB / API が非公開・有償で入口で詰まる。
- ボトルネックはコードじゃない。ベンダー調整、データ品質、規制、臨床的正しさ。

### ベンダー協力しにくい理由と国の対応

- 協力しにくい: ロックインが収益源。連携は他社のためのコスト。競合同士。個別カスタマイズ文化。事故時の責任所在不明。
- 国が外から動かす:
  - 標準規格の義務化・誘導 (3文書6情報、FHIR)。
  - 診療報酬の加算で病院側から圧力 (医療DX推進体制整備加算など。名称・趣旨のみ。要件・点数は未確認)。
  - 標準型電子カルテ = 競争圧力。
  - 全国医療情報プラットフォーム = ハブ&スポーク。n社 × n社 を n社 × 1 に。
- ハブ型は漏洩時の影響範囲が大きい。トレードオフ。

### 業界の性質

- 人気ない理由 (推測): 納期・要件が現場都合。失敗許容度低い。調達遅い。予算限られる (特に介護は報酬公定)。規制対応コスト。
- 機会: 課題明確で価値大。人手不足は構造的。競合少ない。国が後押し。
- コード書くのAIで安くなった分、現場理解して信頼得て導入まで持ってく力が差別化。ただ労力高いので報酬高くないと人来ない。補助金・加算は予算の天井を引き上げる役。ただし期間限定で、終わると需要落ちる面あり。
