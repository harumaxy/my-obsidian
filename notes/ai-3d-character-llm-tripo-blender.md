## 結論

- 原始人、思う。よくある型。
    - 3D メッシュ生成 = image-to-3D サービス (**Tripo**) 主役
    - LLM = Blender で配置・調整・リグ・修正の雑用担当
- 「LLM だけで 3D 作った」は誤解。著者本人もリプライで訂正してる。

## 工程

1. 立ち絵を AI 画像生成で用意
2. 立ち絵から 8 パーツ PNG (背景透過) に分解
    - 帽子 / 髪 / 頭 / 肩飾り / ケープ / 腰コード / 衣装 / 脚
    - 見えない部分も AI が補完。「バラして」で簡単にできる
3. パーツごとに Tripo で 3D 化 (別々生成)
4. Blender で組み立て
    - 位置とスケール合わせ = LLM 担当。ただし Astra の組み立ては大雑把、ずれは手作業で調整
5. リギング (Opus 5.5)
    - 71 ボーン、足 IK、髪・衣装の揺れ、まばたき・口形・表情
    - 揺れはデフォルトだと控えめ → 強調させた
6. ポーズテストで不具合探し
    - 腰が腕に引っ張られる / 脚がスカート貫通 / 腰コードが留め具ごとずれる
    - 表情重ねるとまぶた崩れる / 上向きで顎が伸びる
7. 修正 (主に Astra)
    - ウェイト調整、顎を頭追従、裾に脚連動補正、コード上端をベルト追従
    - 口の奥行き (唇・歯・舌)、白目が暗く沈むのを明るさ補正
8. ダンス適用 (Opus 5.5): 動画由来モーション、約 15 秒、`jill_dance.blend`
9. 微調整: 腕ペラペラ→ウェイト塗り直し、こめかみのハゲ修正、テクスチャと体型を一枚絵に寄せる

## ポイント

- 気になる箇所を画像で共有 → 直させる、の往復が品質を上げる
- 立ち姿だけでは分からない不具合は、動かして初めて出る
- 修正後も同じポーズ+表情の組み合わせで再テストすると再発を見つけやすい (リプライ)
