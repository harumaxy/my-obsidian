## AI エージェント / ハーネス

### imozuru (Claude Code スキル)
- 未知分野の用語・研究者から、参考文献・引用先・著者の別論文へ調査を広げるスキル。
- 原文は要約せず保存。最後は結論レポートでなく「主張ごとに原文該当箇所を並べた抜き書きページ」。抜き書きが指定行に原文一致しないとページ作らない → AI の引用改変防止。
- 調べ始めにキレイにまとめると探索が止まる、という思想。
- [@sora_biz](https://x.com/sora_biz/status/2113515874149666939)

### Anthropic sandbox-runtime OSS 化
- A 社が自社 sandbox を OSS 公開。anthropics/sandbox-runtime。
- ファイルシステム・ネットワーク制限を強制する軽量サンドボックスツール。
- [@criscxuan](https://x.com/criscxuan/status/2113809281661514182)

### Reason (無料ハーネス)
- Terminal-Bench 4.0 で Codex+Astra に勝ち、コスト 22% 安いと主張。
- アプリ版は Mac のみ、CLI は全 OS。オフライン利用を選ぶと無料でDL可。
- [@studio_yebisu](https://x.com/studio_yebisu/status/2110233925465575550)

- 別ポストで「DeepSeek v4.1 Flash + dsh は本物」と評判。
- [@sahenjpn](https://x.com/sahenjpn/status/2106636746658308369) / [@remydre8](https://x.com/remydre8/status/2106736579964539172)

### Pi Durable
- JS ランタイムがあればどこでも永続化できるハーネス。自動コンパクション・クラッシュ耐性・マルチプレイヤー対応。

## Jev (decision モデル) / RAG

### retriever-free RAG
- 階層ツリーを Jev で下って文書を探す。ベクタ DB・BM25 索引不要。
- 弱点: 文書分類が事前に分からないと階層ルールが決まらない。
- (関連ポストはこのスレの「もっと見つける」欄で見た内容。単体タブは無し)

### pg-jev
- Postgres 拡張。SQL 関数 `jev()` (WHERE 内) / `jev_prob()` / `jev_choice()` / `jev_score()` で意味的条件を扱う。
- ベクタ列・埋め込み索引なし。行をバッチして Jev へ送り型付きで返す。
- github.com/realZachi/pg-jev。
- [@_avichawla](https://x.com/_avichawla/status/2106328920211800165)

### TypeLLM
- 型安全な生成 (string / number / boolean / enum、vision、依存フィールド、thinking)。
- Playground は $5 クレジット付きで公開、API は early access。
- [@TypeLLM](https://x.com/TypeLLM/status/2104934225480708133)

## Cloudflare

### cf CLI (Wrangler の後継的位置)
- Cloudflare API 全操作 (3,000+) を叩ける新 CLI。Wrangler は約 280 コマンドのみ。
- `cf deploy`、自然言語検索 `cf cli search`、`cloudflare.config.ts` で型安全な構成管理。SDK 生成基盤 Forge も OSS。
- Wrangler の AI 利用率が 3月 25% → 48%。
- [@yusukebe](https://x.com/yusukebe/status/2104589879812472879) / [@masahirochaen](https://x.com/masahirochaen/status/2105084720749138073) / [@furoku (note 解説)](https://x.com/furoku/status/2104647537852576183)

### vinext 1.0
- Next.js を Vite 上で動かす vinext が 1.0。Cloudflare 公式 docs は OpenNext 非推奨で vinext に置換。
- Birthday Week 2026 で情報多数。
- [@R0u9h](https://x.com/R0u9h/status/2104992311478472991)

### Cloudflare が CA に

## 3D / 画像生成 AI

### Tripo P2.0 でキャラモデル作り直し
- 素体の上に衣装が重なる構造で出力 → 素体から衣装へウェイト転送可能、ウェイト塗り時間が約 9 割減。
- 口 (上下唇分離・口内) や頭部トポロジーが改善。髪だけは P1.0 の方が良かった。
- UV は相変わらず崩れる。三角面→四角面変換で UV ズレ。Tripo 作業 20 分、残りは Blender で人力。PR 案件だが欠点も書く。
- [@Dstudio_ai](https://x.com/Dstudio_ai/status/2093181797412790519)

### Kimi K3.1 Pro で画像→3D (GLB)
- 画像からキャラ 3D を一発生成、約 5 分・約 $0.6。Tripo プラグイン未使用で本モデル自力モデリング。
- ハーネス上で GLB プレビュー可。「3D 生成サービス不要では」という主張。有料パートナーシップ表記あり。
- [@lucianlamp](https://x.com/lucianlamp/status/2113882041444094366)

### Scenario が 3D モデル 1,300+ を HF に公開
- 39GB、CC BY 4.0 (商用可)。Hitem3D / Meshy / Rodin / Tripo / Opus 5.5 / Astra 製。
- 各例に入力画像・プロンプト・設定同梱。GLB 最大 8K テクスチャ、Opus・Astra 製は Blender ネイティブ。ゲーム転用できる品質との評。
- [@Scenario_gg](https://x.com/Scenario_gg/status/2113635335267643591) / [@studio_yebisu](https://x.com/studio_yebisu/status/2113920328535830617)

### ComfyUI: Idol (画像1枚→360° 3D)
- 2026-10-28 公開の Image-to-3D。出力は Gaussian Splat (.ply)、メッシュではない。
- 背面・側面は AI 推定、再現保証なし。VRAM は少なめ。
- 試すと足が消える・後頭部が「無」になる。
- [@NobinLOG](https://x.com/NobinLOG/status/2117460865763164386)
