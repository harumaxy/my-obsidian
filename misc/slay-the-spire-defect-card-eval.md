# Slay the Spire ディフェクト カード評価

- 1HPニキ (A20H勝率53%) ずんだもん解説

## 全体の軸

- 勝ち筋 = 集中力 + フロスト生成。毎ターン ブロック大量
- セットアップ速度 命。ドロー、エナジー生成、0コスト 優先
- 序盤 避弾 抑える。0コストブロック、デバフ。2層道中 特に危険
- UG優先 = 1枚で効果 劇的に変わるもの

## アタック編

- ストライク/防御 削除: 初期レリック 攻撃寄り → ストライク先。でもデッキバランス見て決める
- 最優先
  - 切断: 最強アタック。取ったら即UG。複数戦・ミニオン処理強い
  - 自望時期 (AOE+ダーク): 1層で優先
- 強い
  - コンパイルドライバー: 迅速セットアップ支える
  - FTL: 序盤 取っていい
  - ビームセル / ブルズアイ: デバフ。アーティファクト剥がし
  - カパ / ボールライトニング: 序盤主力。フロスト生成 大事
  - ブリザード / サンダーストライク: 終盤火力。心臓戦
  - 集中放火: スロット数比例。心臓戦タイムリミット対策
- 条件付き
  - ハイパービーム: 1層前半 仕方なく。反響化 or 認知変更あれば強い
  - メテオストライク: 使えるデッキなら壊れ。エナジー生成必須。先ピックNG
  - オール4: ホログラムの方が汎用
- 取らない: 爪、スクレイク

## スキル編

- 最優先級
  - 検索: 無条件サーチ。ピン詰め最強
  - 遺伝的アルゴリズム: 1層で出たら最優先。2ターン目被弾対策
  - 融合: プラズマ生成。デッキ圧縮できれば無限ループ部品
  - 商人 (集中力): 逃したら出ない。優先
  - 核分裂: 3エナジー3ドロー以上
  - 集計: 山札厚い中盤以降 エナジー生成として強い
- 安定枠
  - 冷静沈着: 2層以降 カパより強い
  - 加速: エナジー生成で一番使いやすい
  - 充電、均衡、強化ボディ、サムけ (0コスト廃棄フロスト)、機動シーケンス
- 使い所選ぶ
  - ホログラム: 回収。強い
  - リサイクル: デッキ圧縮用
  - ダブルエナジー: 3エナ段階では弱い
  - マルチキャスト、再起動: 状況限定
- ザップ: UGで0コスト → 化ける

## パワー編

- 出たら基本取る
  - デフラグ: 集中力。最優先。UG優先度も高い
  - 反響化: 最強クラス。重ねがけも取る。自己修復と相性良い
  - 認知変更: 集中力大量。アーティファクトでデメリット無効
  - 電気力: 2層複数戦対策
  - クリエイティブAI: 負け確定 → ワンチャン。運ゲー
- 状況で取る
  - コンデンサ: オーブ生成 揃ってから。商人あれば序盤でも優先
  - ヒートシンク: パワー枚数とエナジー生成 足りてる時
  - バッファー: 一撃重い相手に強い
  - 自己修復: 回復。2枚目は取らない
- 弱い: ストーム、機械学習、ハローワールド (序盤限定、UG不要)

## デッキビルドの種類

(動画中の言及から整理)

- フロスト・集中力型 (基本の勝ち筋)
  - 集中力 + フロスト生成で毎ターン大量ブロック → 余裕で耐久
  - 要: デフラグ、商人、認知変更、カパ、冷静沈着
  - 目安: 浮いてるフロストだけで60ブロック → 心臓戦も安泰
- ダーク型 (ボス突破・長期戦)
  - ダークを育てて解放。デュアルキャストで2回解放、再期で再生成
  - 要: 自望時期、暗黒、ルーク (3倍速で育つ)、デュアルキャスト
  - 心臓戦はダーク最大200点まで → 再期で繰り返し解放
- ライトニング型 (火力型)
  - サンダーストライク、集中放火、電気力 (複数戦)
  - 防御不安定になりやすい → フロスト多め必須
- 無限ループ型 (上級者向け)
  - リサイクルでデッキ圧縮 + ドロー + エナジー生成で無限回転
  - 要: 融合、冷静沈着、ホログラム、メテオストライク
  - UG要求値 高い。圧縮必須
- 「再構築」連打型: 専用構築。2層ボス前にオーブも集中力も無い時の最終手段。基本非推奨
- 万能補助: 反響化 + パワー複数枚、クリエイティブAI (ボスへの回答ない時の勝ち筋)
